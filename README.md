# 🐎 uma-note

週末のメインレースを気楽に楽しむための、ローカル動作型・出走馬ビューワーです。  
JRAの出馬表URLを入力するだけで、各馬の血統（系統色分け）・脚質・過去1年分の戦績（競馬場・距離・馬場・タイム・馬体重）を見やすいカード形式で整理できます。

## 主な機能
* **JRA出馬表URLからの自動取り込み**
  * 出馬表ページから全頭の基本情報と個別ページリンクを取得し、ランダムな順番＆ゆらぎウェイト（2〜4秒）で各馬の過去走を遅延ロードします。
* **ローカルキャッシュ**
  * 取得した馬ごとの履歴は `cache/horses/{馬名}.json` に1頭1ファイルでキャッシュされ、2回目以降は即座に読み込まれます。
  * 現在のレース状態・ピン留め・メモは `cache/state.json` に自動保存されます。
* **見やすいカードUI**
  * **血統バッジ**：父・母・母父を表示し、種牡馬系統を色で直感的に区別。
  * **脚質自動判定**：直近のコーナー通過順位から `#逃げ` / `#先行` / `#差し` / `#追込` を自動タグ付け。
  * **過去走横スクロール**：日付・競馬場・着順・レース名・距離・馬場・タイム・馬体重を一覧表示。
* **📌 気になる比較**
  * 気になった馬をピン留めして、一覧と同じレイアウトで絞り込み表示できます。

## 使い方

1. ローカルサーバーを起動します（Python 3 標準ライブラリのみで動作します）：
   ```bash
   python3 server.py
   ```
2. ブラウザで `http://localhost:8000` を開きます。
3. 右上の **「📋 出馬表を取り込む」** からJRAの出馬表URLを入力して **「URL取得」** を押します。
